# upcoming-events-and-actions

Check upcoming calendar events and recent corporate actions like dividends and stock splits using `yfinance`.

## When to Use

* The user asks for upcoming earnings dates or calendar events for a company or ticker.
* The user wants recent dividend or stock split history from `ticker.actions`.
